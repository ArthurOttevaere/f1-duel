# Têtes des pilotes (placeholders)

Dépose ici les vraies photos des pilotes. Tant qu'une photo est absente,
l'interface affiche automatiquement un avatar avec les initiales du pilote
sur la couleur de son équipe.

## Convention de nommage

Une image **carrée** (idéalement 256×256 ou 512×512), au format **PNG**,
nommée d'après le `driver_id` du modèle :

```
webapp/static/drivers/max_verstappen.png
webapp/static/drivers/norris.png
webapp/static/drivers/leclerc.png
webapp/static/drivers/hamilton.png
```
