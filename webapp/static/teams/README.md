# Team logos / badges (optional)

Drop team logos here. When a logo is missing, the interface automatically shows
a colored monogram (e.g. `RBR`, `FER`, `MCL`) in the team's color instead.

## Naming convention

A **PNG** (ideally square, transparent background), named after the team slug —
the team name lowercased with non-alphanumeric characters replaced by `_`:

```
webapp/static/teams/red_bull_racing.png
webapp/static/teams/ferrari.png
webapp/static/teams/mercedes.png
webapp/static/teams/mclaren.png
webapp/static/teams/aston_martin.png
webapp/static/teams/alpine.png
webapp/static/teams/williams.png
webapp/static/teams/racing_bulls.png
webapp/static/teams/kick_sauber.png      # or audi.png
webapp/static/teams/haas_f1_team.png
webapp/static/teams/cadillac.png
```

> A transparent background renders best inside the rounded badge.
> No need to restart the server after adding an image.
